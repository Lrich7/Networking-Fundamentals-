# Getting Started --- Tools & Lab Setup

Welcome to **Networking Fundamentals**.

This page prepares your computer for the hands-on labs and projects used
throughout the course. The goal is to create a useful networking lab
without requiring physical Cisco equipment or a paid lab subscription.

> **Recommended platform:** Windows 10 or Windows 11. Most networking
> concepts also apply to Linux and macOS, but some later labs use
> Windows and PowerShell networking tools.

------------------------------------------------------------------------

# What You Will Use

- **Cisco Packet Tracer — Required**

- **Wireshark — Required**

# 1. Cisco Packet Tracer

Cisco Packet Tracer is the primary network simulator used throughout
this course.

You will use it for:

-   Network topologies
-   Ethernet and switching
-   IPv4 and IPv6
-   Subnetting
-   VLANs and trunks
-   Routing
-   DHCP and DNS
-   Wireless networking
-   ACLs and segmentation
-   Troubleshooting
-   Packet flow and Simulation Mode

## Official URLs

**Packet Tracer information:**\
https://www.netacad.com/cisco-packet-tracer

**Packet Tracer Resource Hub / downloads:**\
https://www.netacad.com/resources/lab-downloads

**Getting Started with Cisco Packet Tracer:**\
https://www.netacad.com/getting-started-cisco-packet-tracer

> Cisco provides Packet Tracer for Windows, Linux, and macOS. You may
> need to sign in with a free Cisco Networking Academy account to access
> the software.

## Installation

1.  Open the Cisco Resource Hub.
2.  Sign in or create a Cisco Networking Academy account if prompted.
3.  Locate **Cisco Packet Tracer**.
4.  Download the version for your operating system.
5.  Run the installer.
6.  Accept the license agreement.
7.  Complete the installation.
8.  Launch Packet Tracer.
9.  Sign in if prompted.

## Verification Test

Build:

``` text
PC0 ---------------- PC1
```

Configure:

``` text
PC0
IP Address: 192.168.1.10
Subnet Mask: 255.255.255.0

PC1
IP Address: 192.168.1.20
Subnet Mask: 255.255.255.0
```

On PC0, open **Desktop → Command Prompt** and run:

``` text
ping 192.168.1.20
```

If you receive replies, Packet Tracer is working.

Do not worry if you do not yet understand why these addresses work. IPv4
addressing and subnetting are covered later.

# 2. Wireshark

Wireshark is a free, open-source network protocol analyzer.

You will use it to observe traffic such as:

``` text
ICMP
ARP
DNS
DHCP
TCP
```

## Official URLs

**Wireshark:**\
https://www.wireshark.org/

**Download:**\
https://www.wireshark.org/download.html

**User's Guide:**\
https://www.wireshark.org/docs/wsug_html/

## Installation on Windows

1.  Open the official Wireshark download page.
2.  Download the current stable Windows installer.
3.  Run the installer.
4.  Keep the normal components selected unless you have a reason to
    change them.
5.  Allow installation of **Npcap** when prompted.
6.  Finish the installation.
7.  Open Wireshark.

Npcap enables live packet capture on Windows and is included with the
official Windows installer.

## Verification Test

1.  Open Wireshark.
2.  Select your active Ethernet or Wi-Fi interface.
3.  Start a capture.
4.  Open Command Prompt or PowerShell.
5.  Run:

``` text
ping 8.8.8.8
```

6.  Stop the capture.
7.  Enter this Wireshark display filter:

``` text
icmp
```

You should see ICMP traffic generated by the ping.

> Only capture network traffic on systems and networks where you are
> authorized to do so.

PowerShell provides more advanced Windows networking and automation

installed side-by-side.

## Official URLs

https://learn.microsoft.com/powershell/scripting/install/install-powershell-on-windows

## Verify PowerShell

Run:

``` powershell
$PSVersionTable
```

## Optional --- Install PowerShell 7

On a supported Windows client, Microsoft documents WinGet as a
recommended installation method:

``` powershell
winget install --id Microsoft.PowerShell --source winget
```

Start PowerShell 7 with:

``` text

```

## Test Networking Cmdlets

``` powershell

```

``` powershell

```


You will learn what these commands tell you in later lessons.

# 8. Basic Network Verification

Open Command Prompt and run:

``` text
ipconfig
```

Locate:

``` text
IPv4 Address
Subnet Mask
Default Gateway
```

Then run:

``` text
ping 127.0.0.1
```

Next:

``` text
ping 8.8.8.8
```

Finally:

``` text
nslookup example.com
```

These tests check different parts of networking. Later lessons explain
exactly what each test proves.

# Troubleshooting Setup

## Packet Tracer Will Not Open

-   Verify that you downloaded the correct version for your operating
    system.
-   Restart the computer if necessary.
-   Check Cisco's current Packet Tracer documentation.
-   Verify that you can sign in to your Cisco account if authentication
    is requested.

## Wireshark Shows No Interfaces

On Windows, verify that Npcap was installed.

Re-run the official Wireshark installer if necessary.

## PowerShell Networking Command Not Found

Commands such as:

``` powershell
Get-NetAdapter
Get-NetIPConfiguration
```

are Windows-specific. Verify that you are completing the Windows version
of the lab.

## Internet Ping Fails

A failed ping does not automatically mean the internet is unavailable.
ICMP can be blocked.

Try:

``` powershell
Test-NetConnection example.com -Port 443
```

Later troubleshooting lessons explain the difference.

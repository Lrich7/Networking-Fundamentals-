# 🧪 Networking Fundamentals — Labs

Welcome to the **Networking Fundamentals Labs**.

The lessons teach you **what networking technologies do**.

The labs teach you how to **see them, use them, configure them, and troubleshoot them**.

You do not need previous networking experience to begin. Early labs provide detailed instructions, while later labs gradually require more independent problem-solving.

---

# 🎯 Lab Goals

Throughout these labs, you will learn how to:

- Examine a computer's network configuration
- Use Windows networking commands
- Use PowerShell networking tools
- Build networks in Cisco Packet Tracer
- Configure IPv4 and IPv6 addressing
- Calculate and test subnets
- Configure switches and routers
- Work with VLANs
- Configure DHCP and DNS
- Examine network traffic with Wireshark
- Troubleshoot connectivity problems
- Document network environments
- Apply basic network security
- Diagnose problems using a structured methodology
- Prepare for hands-on concepts associated with CompTIA Network+ N10-009

---

# 🧰 Lab Tools

Different networking concepts are best learned with different tools.

Throughout the course, labs may use:

| Tool | Purpose |
|---|---|
| 🪟 **Windows** | Examine and troubleshoot a real workstation |
| 🔷 **PowerShell** | Network configuration and investigation |
| ⌨️ **Command Prompt** | Traditional networking utilities |
| 🌐 **Cisco Packet Tracer** | Build and configure simulated networks |
| 🦈 **Wireshark** | Capture and analyze network traffic |
| 🗺️ **Network Diagrams** | Design and document networks |
| 🧠 **Scenarios** | Practice troubleshooting and decision-making |

Not every lab uses every tool.

We'll use the tool that best demonstrates the concept.

# 🎓 Network+ Lab Strategy

Network+ preparation shouldn't only involve memorizing definitions.

Throughout these labs, you'll practice questions such as:

> A workstation can ping its gateway but cannot access websites by name. What should you investigate next?

or:

> Two computers are connected to the same switch but are assigned to different VLANs. Why can't they communicate directly?

or:

> A workstation has an address beginning with `169.254`. What does that tell you?

The goal is to recognize the **symptoms** of a networking problem and determine the most logical next troubleshooting step.

# 📊 Lab Difficulty

The labs will gradually become less guided.

### 🟢 Beginner

```text
Follow the instructions.
Observe what happens.
Answer questions about what you see.
```

### 🔵 Intermediate

```text
Build the requested network.
Configure the required services.
Verify that everything works.
```

### 🔴 Advanced

```text
Here are the symptoms.

Something is wrong.

Find it.
Fix it.
Prove that you fixed it.
Document what happened.
```

By the end of the course, troubleshooting labs will intentionally avoid telling you exactly which command to run.

Choosing the correct troubleshooting tool is part of the exercise.
